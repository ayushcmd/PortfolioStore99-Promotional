# Support for PortfolioStore 99

This repository contains **promotional documentation, brand guidance, product information, and architectural specifications** for [PortfolioStore 99](https://www.portfoliostore99.in). The storefront application and commercial portfolio template source code are maintained separately and are **not** included here.

Choose the support channel that fits your question.

## Where to get help

| Your request | Recommended channel |
| --- | --- |
| Help purchasing a template, payment or receipt questions, download access, or a template delivery issue | Email [portfoliostore99@gmail.com](mailto:portfoliostore99@gmail.com) |
| General information about the store or available templates | Read the [storefront](https://www.portfoliostore99.in) and this repository's [README](README.md) |
| Errors, broken links, or outdated information in this public documentation repository | [GitHub Issues](https://github.com/ayushcmd/PortfolioStore99-Promotional/issues) |
| Suggestions about the promotional documentation or specifications | [GitHub Issues](https://github.com/ayushcmd/PortfolioStore99-Promotional/issues) or [Discussions](https://github.com/ayushcmd/PortfolioStore99-Promotional/discussions) |
| General questions and non-sensitive community discussion | [GitHub Discussions](https://github.com/ayushcmd/PortfolioStore99-Promotional/discussions) |
| A suspected security vulnerability | Follow [SECURITY.md](SECURITY.md) and **report privately** |
| Harassment or conduct violations in the repository community | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for confidential reporting |
| Permission to reuse or distribute proprietary materials | Review [LICENSE](LICENSE) and contact [portfoliostore99@gmail.com](mailto:portfoliostore99@gmail.com) |

**Customer support and public repository issues are different.** For order-specific questions, avoid public GitHub posts and contact the store directly instead.

## Storefront and purchase support

When emailing the store, include a short explanation of the problem and the template or product involved. If you have an order reference, use it in a **private email only**. Never publish payment details, receipts, customer email addresses, download links, or order identifiers in public Issues or Discussions.

The [storefront](https://www.portfoliostore99.in) publishes its current policies:
- [Terms of Service](https://www.portfoliostore99.in/terms)
- [Privacy Policy](https://www.portfoliostore99.in/privacy-policy)
- [Refund Policy](https://www.portfoliostore99.in/refund-policy)

The public repository summarizes these policies, but the current terms on the official storefront govern customer purchases. If policies or prices differ, ask the store for clarification before relying on an outdated documentation copy.

## Documentation bugs and improvements

Before opening an issue, read the [README](README.md), browse the relevant file under [docs/](docs/), and search [existing issues](https://github.com/ayushcmd/PortfolioStore99-Promotional/issues).

For a documentation correction, include:
1. The file, heading, or URL affected.
2. What is inaccurate, broken, unclear, or missing.
3. The suggested correction and supporting source, where possible.
4. Any relevant screenshots with personal or proprietary information removed.

For feature proposals or broader conversations about the promotional documentation, use [GitHub Discussions](https://github.com/ayushcmd/PortfolioStore99-Promotional/discussions) if a discussion is more suitable than a tracked issue.

To propose a documentation change, review [CONTRIBUTING.md](CONTRIBUTING.md), including the approval and rights restrictions applicable to this proprietary repository.

## Sensitive issues and privacy

**Do not publicly post** passwords, API keys, access tokens, payment data, order details, private customer information, unpublished storefront source code, or other confidential material.

- Technical vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md).
- Community conduct complaints belong with the confidential contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Private customer support should go to [portfoliostore99@gmail.com](mailto:portfoliostore99@gmail.com).

## Response expectations

Support is handled on a best-effort basis unless an applicable published store policy provides a specific commitment. This document does not promise guaranteed GitHub issue response times or changes to purchase rights, refunds, or replacement terms.

Thank you for helping keep PortfolioStore 99's promotional documentation accurate and useful.
